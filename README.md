# 밤의 카페 테라스 3D

빈센트 반 고흐의 「밤의 카페 테라스」(1888)를 걸어 다닐 수 있는 1인칭 3D 마을로 만든 웹 게임입니다. three.js와 붓터치 후처리 셰이더(쿠와하라 필터 + 윤곽선)로 그림의 질감을 살렸습니다.

**플레이:** https://usuu94152-collab.github.io/cafe-terrace-3d/

## 할 수 있는 것
- 노란 차양 카페와 테라스, 카페 내부(「밤의 카페」 오마주), 분수 광장 산책
- 주민 18명과 대화, 테라스에 앉아 주문하기
- 퀘스트: 화가의 물감 5색 찾기, 우체부의 편지 배달
- 그림 해설 안내판 7개, 수첩(지도·의뢰·만난 사람·그림 이야기·스케치북)
- 스케치 모드로 장면 담기, 진행 상황 자동 저장(브라우저 localStorage)

## 조작
| 키 | 동작 |
|---|---|
| W A S D / 방향키 | 걷기 (Shift 달리기) |
| 마우스 | 둘러보기 (클릭해서 고정) |
| E | 말 걸기 · 앉기 · 안내판 읽기 |
| J / Tab | 수첩 · 지도 |
| C | 스케치 |
| P | 붓터치 효과 켜고 끄기 |
| M | 음악 |

휴대폰에서는 왼쪽 조이스틱으로 걷고, 화면 오른쪽을 끌어서 둘러봅니다.

## 구조
단일 `index.html` 파일입니다. 외부 의존성은 cdnjs의 three.js r128과 Google Fonts뿐입니다.
